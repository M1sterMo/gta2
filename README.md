# GTA2 in your browser

The 1999 game, running in the browser from the community's reconstruction of its code
([gta2_re](https://github.com/CriminalRETeam/gta2_re)), compiled to WebAssembly.

**Play:** https://m1stermo.github.io/gta2/

- Nothing is installed. The first time you press Play, the page downloads the official 2004
  freeware release of GTA2 from the [Internet Archive](https://archive.org/details/gta2_rockstar-classics)
  into your browser (362 MB), unpacks it there and keeps it for next time.
- This repository holds only the built web code: **no game files**.
- Co-op (free roam, Gang Wars, free-for-all) connects players directly, browser to browser.
